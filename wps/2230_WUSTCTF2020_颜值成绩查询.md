# [WUSTCTF2020]颜值成绩查询

## 题目概述
题目是一个成绩查询系统，用户输入学号 `stunum` 参数查询成绩，返回学生姓名和分数。

## 信息收集
1. 访问页面，发现是 PHP 后端（从错误信息可见）
2. 测试 `stunum=1` 返回 "Hi admin, your score is: 100"
3. 测试 `stunum=1'` 返回 "student number not exists"（无报错，可能有过滤）
4. 测试 `stunum=1 or 1=1` 返回 "student number not exists"（空格被过滤）
5. 测试 `stunum=1/**/and/**/1=1` 返回正常数据，`/**/and/**/1=2` 返回空，确认 SQL 注入存在

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：布尔盲注 SQL 注入

**原理**：
- 后端 SQL 查询类似 `SELECT * FROM score WHERE stunum='$input'`
- 空格被 WAF 过滤，但可用 `/**/` 注释绕过
- 通过布尔条件判断逐字符提取数据

**判断过程**：
- `1/**/and/**/1=1` → 返回正常数据（条件为真）
- `1/**/and/**/1=2` → 返回空（条件为假）
- 确认存在布尔盲注

## 复现步骤
1. 访问题目 URL，发现学号查询功能
2. 测试 SQL 注入：`?stunum=1/**/and/**/1=1` 确认存在
3. 使用 `/**/` 绕过空格过滤
4. 通过布尔盲注提取数据库结构
5. 从 `flag` 表的 `value` 列提取 flag

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| SQL注入 | stunum 参数 | `1/**/and/**/ascii(substr(...))>n` | 空格过滤绕过、布尔盲注、二分查找优化 |

## 知识总结（解题技巧、同类题型套路）
1. **空格过滤绕过**：`/**/`、`%0a`、`%09`、`+`、括号等
2. **布尔盲注优化**：使用二分查找减少请求次数，时间复杂度从 O(n*95) 降到 O(n*log(95))
3. **信息收集顺序**：database() → tables → columns → data
4. **group_concat**：一次性获取所有表名/列名，减少查询次数
