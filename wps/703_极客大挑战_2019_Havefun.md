# [极客大挑战 2019]Havefun

## 题目概述
一个展示CSS动画猫的网页，需要通过分析源码找到获取flag的方法。

## 信息收集
访问目标URL，返回一个带有猫咪CSS动画的HTML页面。通过`curl -v`获取完整源码后，在HTML注释中发现PHP代码片段。

## 漏洞分析
页面源码中包含被注释掉的PHP代码：
```php
<!--
$cat=$_GET['cat'];
echo $cat;
if($cat=='dog'){
    echo 'Syc{cat_cat_cat_cat}';
}
-->
```
该代码从GET参数`cat`获取输入，当值为`dog`时输出flag。

## 利用过程
```bash
curl "http://TARGET:PORT/?cat=dog"
```
响应中直接包含flag字符串。

## 复现步骤
1. `curl -s "http://TARGET:PORT/?cat=dog" | grep "flag{"`

## 注意事项
- 入门级Web题，考察HTML源码审计意识
- flag不在PHP注释中（注释里的是占位符`Syc{...}`），实际flag由服务端逻辑输出The flag is embedded in the page source when `cat=dog` is passed. The PHP code echoes the flag when the condition is met.

**Flag:** `flag{44bb8cae-909b-4670-a796-882af30fa900}`
