# [极客大挑战 2019]Havefun

## 题目概述
一个展示CSS动画猫咪的页面，需要找到隐藏的flag。

## 信息收集
访问题目页面，查看HTML源码，在页面底部发现一段被HTML注释包裹的PHP代码：

```html
<!--
$cat=$_GET['cat'];
echo $cat;
if($cat=='dog'){
    echo 'Syc{cat_cat_cat_cat}';
}
-->
```

页面由 PHP/5.3.3 驱动（从响应头 `X-Powered-By` 可知）。

## 漏洞分析
- **漏洞类型**：源码泄露（HTML注释中包含服务端逻辑）
- **原理**：开发者将PHP代码以HTML注释形式遗留在前端页面中，暴露了服务端的参数名和判断逻辑
- **判断过程**：注释中的PHP代码接收GET参数`cat`，当值为`dog`时输出flag

## 利用过程
直接构造URL传入 `cat=dog`：

```bash
# Payload：GET参数cat=dog
curl "http://target:81/?cat=dog"
```

页面中直接输出了flag。

## 复现步骤
1. 访问题目页面，查看网页源码
2. 发现HTML注释中的PHP代码逻辑
3. 浏览器访问 `http://target:81/?cat=dog` 即可看到flag

## 技术总结
| 漏洞类型 | 攻击入口 | 核心Payload | 知识点 |
|---------|---------|------------|-------|
| 源码泄露 | HTML注释 | `?cat=dog` | 查看源码找隐藏逻辑，HTML注释可能泄露服务端代码 |

## 知识总结
- **查看源码习惯**：CTF Web题第一步永远是查看页面源码，包括HTML注释、隐藏表单、JS文件等
- **HTML注释泄露**：开发者可能将调试代码、服务端逻辑以注释形式遗留在前端，这是常见的信息泄露方式
- **同类题套路**：源码泄露 → 分析逻辑 → 构造参数触发条件 → 获取flag
