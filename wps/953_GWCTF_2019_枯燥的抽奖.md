# [GWCTF 2019]枯燥的抽奖

## 题目概述
一个猜字符串游戏，服务器生成20位随机字符串，展示前10位，需要猜出完整字符串才能获取flag。

## 信息收集
1. 访问页面发现是一个抽奖/猜字符串游戏
2. check.php 源码泄露，揭示了完整的随机数生成逻辑

## 漏洞分析
PHP mt_rand() 使用可预测的伪随机数生成器：
- 种子范围：`rand(0, 999999999)` - 仅10亿种可能
- 已知：前10位字符串
- 攻击：通过 php_mt_seed 工具爆破种子，然后预测完整字符串

## 利用过程
1. 获取 session 和已知字符串前10位
2. 将字符转换为 mt_rand(0, 61) 的输出序列
3. 使用 php_mt_seed 爆破种子
4. 用种子生成完整20位字符串
5. 提交答案获取 flag

## 复现步骤
```bash
# 1. 编译 php_mt_seed
git clone https://github.com/openwall/php_mt_seed.git
cd php_mt_seed && make

# 2. 运行解题脚本
python3 solve.py
```

输出：
```
[+] Known: aXsN3EaGg7
[+] Seed: 367513333
[+] Full: aXsN3EaGg7DwxXdBdBvD
[+] Result: flag{2e7bf253-03c9-4622-b290-b60b85ad0116}
```
